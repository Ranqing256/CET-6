# 六级词汇本

面向大学英语六级备考的个人词汇本。支持按听力、完形填空、阅读、翻译、作文管理生词，并提供首字母索引、搜索、单词卡、词条编辑和删除。

## 正式网站

**下次请从这个 Vercel 正式入口访问：<https://cet-6-xs4c.vercel.app>**。向 GitHub 仓库的 `main` 分支推送代码后，Vercel 会自动构建和部署；部署成功后，这个正式网址会显示最新版本。每次构建的预览链接可能不同，不要把预览链接当成长期入口。GitHub Pages 当前未启用，因此 GitHub 仓库设置中的 Pages 地址不是本项目的正式网站入口。

## 学习功能

- **间隔复习**：先回想、再揭晓释义；标记“认识”后按 1、3、7、14、30 天间隔复习，标记“再复习”则 10 分钟后重新到期。
- **英语发音**：可在页面中选择当前设备/浏览器提供的英语音色，或使用自动选择；具体语音取决于设备安装的语音与浏览器支持情况。
- **备份与恢复**：下载包含词条和复习进度的 JSON 备份；导入时按单词忽略大小写去重，不覆盖已有词条。

## 个人词库与跨设备使用

网页代码部署到 Vercel 后会更新所有访问同一正式网址的人；但手动录入的词汇和复习进度保存在当前浏览器的 `localStorage`，不会自动同步到其他浏览器、无痕窗口或设备。需要换设备时，请在原浏览器点击“导出备份”，再在新设备打开正式网址并点击“导入备份”。导入会新增没有的词，重复词会跳过。个人备份只应保存在你自己的设备中，不要提交到公开 GitHub 仓库。

`src/data/repository.ts` 提供统一仓储接口和 `upsertFromAutomation` 自动入库入口；未来可以在另行设计账户和云端同步后替换数据来源，而不必重写界面。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 部署到 Vercel

1. 将项目推送至 GitHub、GitLab 或 Bitbucket，并在 Vercel 导入该仓库。
2. 框架使用 Vite，根目录为 `./`。
3. 构建命令：`pnpm build`；输出目录：`dist`；安装命令：`pnpm install --frozen-lockfile`。
4. 点击 Deploy。`vercel.json` 已包含单页应用回退规则。
